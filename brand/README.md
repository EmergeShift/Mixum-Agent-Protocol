# MAP brand

The MAP mark is the **mixumOS M**, reused to show that MAP is the contract inside
the same family. It is not a separate product logo; if MAP ever gets its own mark,
this directory will say so.

| File | Use |
|---|---|
| `app-icon.svg` | README / social preview (ink square, paper M) |
| `logo-mark.svg` | light backgrounds |
| `logo-mark-inverse.svg` | dark backgrounds |
| `logo-mark-mono.svg` | single-color print / `currentColor` |

The geometry comes from `mixumos/brand/`; both repositories are Apache-2.0. Keep
the mark solid and single-color; do not add gradients or shadows.
