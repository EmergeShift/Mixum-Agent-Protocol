# MAP brand

Product mark from the **EmergeShift identity kit**: the same square, cut by a
5.2-unit seam. The keyed, rectangular joint reads as a contract that only fits
one way — MAP.

| File | Use |
|---|---|
| `svg/lockup-horizontal.svg` | README header, light backgrounds |
| `svg/lockup-horizontal-inverse.svg` | dark backgrounds |
| `svg/mark.svg` / `svg/mark-inverse.svg` | square mark |
| `svg/app-icon.svg` | app icon / favicon / social preview |
| `svg/avatar.svg` / `svg/avatar-ink.svg` | org and social avatars |
| `svg/wordmark.svg` | wordmark only |
| `png/` | raster exports (32–1024) |

SVGs are the source of truth. Ink `#1A1A18`, paper `#F4F4F2`, transition blue
`#3A46FF` (accent only, never the field). Keep the mark solid and single-colour;
no radius, stroke, gradient or shadow.

The wordmark is Inter SemiBold, outlined. Inter is SIL OFL 1.1; the outlines are
part of this Apache-2.0 repository.
