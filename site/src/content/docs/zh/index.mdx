MCP 标准化了 agent 与**工具**的对话方式。MAP 标准化的是 agent 与其操作者同**环境**的对话方式：在 VM 或容器里执行任务、用快照树进行时间旅行、把整个工作状态在机器间随时搬走、从任何设备观看并接管 GUI 窗口、以及让 agent 记忆跟着人走。

每项能力都由最小权限能力令牌守卫；所有产物按内容寻址；每次语义变更都有版本协商。

  <Card title="有生命周期的任务">

  </Card>
  <Card title="内建的时间旅行">
    每个环境暴露一棵快照树——分支、回退、分叉——机器状态的 git 语义，热到无感。
  </Card>
  <Card title="跨宿主流转">
    合上笔记本去云端继续干，回来再合体。内容寻址的块同步让它幂等且廉价。
  </Card>
  <Card title="跟着 agent 走的记忆">

  </Card>
