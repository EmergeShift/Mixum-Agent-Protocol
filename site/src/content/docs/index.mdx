MCP standardized how agents talk to **tools**. MAP standardizes how agents and their
operators talk to **environments**: run a task inside a VM or container, travel through
time with snapshot trees, move a whole working state between machines mid-flight, watch
and steer GUI windows from anywhere, and carry agent memory with you.

Every capability is guarded by least-privilege capability tokens. Every artifact is
content-addressed. Every semantic change is versioned and negotiated.

<CardGrid stagger>
  <Card title="Tasks with a lifecycle">

  </Card>
  <Card title="Time travel, built in">
    Every environment exposes a snapshot tree — branches, rollback, fork — git semantics

  </Card>

  </Card>
